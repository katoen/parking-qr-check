Zo werkt het

  1. Elke code wordt met PBKDF2-SHA256 (100.000 rondes) en een willekeurige salt per event omgezet.
  2. Het bestand bevat enkel die hashes. Wie het bestand leest, ziet geen geldige codes.
  3. De scantool hasht de gescande code op dezelfde manier en vergelijkt.
